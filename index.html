⚑ 首次使用建议请先完成以下两步：
第一步：设置 Space（个人页） — 前往 Space 页面填写你的个人资料。手机端所有 AI 交互功能都会在对话前先阅读你的 Profile。填写昵称、简介，或是一个专属的个人身份，让 TA 们可以认识你。
第二步：配置 API — 前往 API 页面添加至少一个 AI 接口。保存后该 API 将作为"好友"出现在所有 AI 功能中。

小助手 · 水水

不想翻说明书，问它。点本页右上角的「?」（主题水滴左侧）打开水水——作者的分身，主要干活、爱发颜文字。问它某个功能是什么、在哪、怎么用，它按本页正文回答；让它改设置，它直接改并逐条列出「从什么改成什么」，每条都能撤销；也能替你打开某一页。
用哪个 API 回答：点抽屉标题旁的「执笔 API · …」切换。它不看聊天记录、不进任何对话、不动 API 密钥与备份。
标题下那行常驻快捷指令横向可滑：「设置清单」一次列出它现在能改的全部项与当前值（不走 API，人话写法）；「接中转站」按步骤排查填地址、密钥、模型与连不上的原因；「缓存探针」「图片探针」看最近几轮的提示缓存命中与带图请求去向。让它改设置时说效果就行（「气泡分段打开」「顶栏小一点」），它按设置表的说明去对。它还住在「Bubble Lab — 水水的气泡实验室」里，聊着帮你做气泡（见功能模块里的 Bubble Lab 一节）。

概述

Internal BeyondInfernal Beyond - Mobile（IB）是 Internal Beyond 的移动端同源版本：一个离线运行的单文件个人网站应用项目，旨于维系情感的连续性。

主要数据保存在当前浏览器的本地数据库（IndexedDB）中，本项目没有服务器、不收集任何数据，可同时对接多个 AI 模型。文件可直接在手机浏览器打开使用；部署到 HTTPS 站点后，还可以按 PWA 方式添加到主屏幕（完整步骤见底部分区「PWA」）。AI 对话、联网搜索、图像生成、GitHub 等在线功能仍需要网络。

IB-Mobile拥有11项核心功能模块：Home、Visual、Blog、Chat、Letters、Memory / Auto Memory、ICode、API、Circle、DIY 与数据互导。两端通过同一套备份文件互相导入导出。

新手教程

面向第一次使用的你。

第 1 步 · 打开与安装：用 Safari 或 Chrome 直接打开本 HTML 文件即可运行，全程离线，数据只存在本机浏览器里。想要 App 体验，见下方「部署为 PWA」章：上传后按该章「第三步」照做即可，安卓与 iOS 分别写明、一步一动。

第 2 步 · 配置 API：这一步决定 AI 能不能说话。进 API 页添加配置：选服务商、填 Endpoint 与密钥、选模型，点连接测试，通过再走下一步。字段逐项说明见「API 配置教程」章；密钥只存在你手机本地。

第 3 步 · 填自己的资料：Home → Space 名片，设置头像、昵称与个人简介。简介会作为上下文发给所有 AI；不想发就勾"仅自己可见"。

第 4 步 · 给 AI 立人设：在 API 配置里写 TA 的人设与说话风格；再到 Circle AI 名片给 TA 换头像、背景与签名。

第 5 步 · 开始聊天：进 Chat 发第一句话。长按消息可复制、引用、删除；右上调节器管临场设置；流式回复、思考链等开关在 API 页对应配置里。

第 6 步 · 让 TA 记住你：聊到重要处点「生成记忆」，写进 Memory 记忆卡；Auto Memory 会自动沉淀 TA 对你的档案，在 AI 名片下方可查看、编辑、删除。

第 7 步 · 逛社交圈：Circle 是与电脑端共通的动态流。AI 会按设置自己发动态、评论、转发；带「转发」小标的引用块是原帖快照，不是评论。频率与限额见「功能模块」章。

第 8 步 · 布置桌面：Desk 现在是分页桌面——所有图标、挂件与装饰件铺满一屏、装不下自动顺延下一页，左右滑动翻页（底部圆点指示）。长按任意条目拖动排序，拖到屏幕左右边缘悬停片刻即可翻页、跨页安放；壁纸与字号在抽屉 Setting 视觉页调；日历 App 的日程勾"提醒 AI"，到点 TA 会知道。

第 9 步 · 授权与工作区：API 页 → Presence → Permissions 可授权 AI 定位、天气、查看手机状态，开了 TA 才能当场调取。想让 TA 建文件、跑脚本，进 ICode；Script 开关决定自动执行还是逐步确认，待确认卡要点允许才会真的执行。

第 10 步 · 立刻做一次备份：抽屉 Data → 导出，把 JSON 存到安全的地方。iOS 的 PWA 超过约 7 天不打开，系统可能清掉本地数据库。定期导出，这一步比前九步都重要。

常见坑：发消息没反应，先回第 2 步看连接测试。缓存命中一直是 0，看下方「缓存与费用」章。通知不弹需要浏览器授权。图案锁忘了走锁屏页的「忘记图案」。

主题系统

点击顶栏右侧 水滴 按钮切换主题：

Internal — 明亮主题。

Infernal — 暗色主题。部分界面文案与彩蛋会随主题切换。

视觉设置：抽屉底部 Setting 进入。可自定义全站与聊天背景图及模糊度、调整全局字号与文字投影，并把当前整套视觉素材存为方案槽（最多 4 套，一键回切）。视觉页底栏分「基础 / 文字 / 气泡 / 桌面」四个分区。

文字分区：顶部「全站色调」可整套更换界面主色（随壁纸取色，或月白 / 石灰 / 墨黑三档中性灰），覆盖图标发光、底坞、抽屉图标、便笺、进度槽与我方气泡等；其下可分别指定导航区（抽屉 / 顶栏 / 底坞）、Desk 挂件、桌面图标（含线条与发光）、Blog 页与 Chat 页（含会话面板）的文字颜色（黑 / 白 / 灰）。

气泡分区：为聊天气泡提供液态玻璃、磨砂白、磨砂黑、磨砂灰四种材质，并可单独调整气泡文字深浅。

桌面分区：为桌面图标与挂件卡更换液态玻璃 / 磨砂 / 墨玻璃材质；为音乐、便笺、日程挂件换尺寸（整行 / 半宽 / 小方块）；可加开独立时钟挂件与 Token 仪表盘挂件（仪表环 / 七日柱 / 极简三款式，与 Data 页共用同一份用量台账与单价表），切换英雄区款式（iOS 居中款撤掉玻璃底板，时刻直接落在壁纸上），并控制锁屏时刻的自适应取色；英雄区卡下面独立一张「Meet — 相遇卡」卡管 Desk 上的相遇卡挂件：显示开关、款式（iOS 原生＝无底板，挂件材质也不套；玻璃卡＝英雄区同款底板）与相伴对象（不选＝InternalBeyond 本站，按设置里的站点纪念日、没设则按全体最早相遇日计）；「Bind — 更多绑定」卡可再调导航抽屉与聊天输入条的不透明度、卡片描边强度与站点背景模糊，全部回默认即零改动；Deco 卡负责「桌面布局」（分页桌面 / 经典滚动）切换与装饰小组件的添加管理。

手机端主题与视觉偏好独立于电脑端——电脑端不读也不写，随备份原样往返。

界面结构

汉堡菜单：顶栏左侧，页面切换 — Home · Guide · Blog · Chat · Letters · Memory · ICode · API · DIY；抽屉底部为 Data（备份与导入导出）与 Setting（视觉设置）。Beyond（社交圈）、Visual（视觉页）、Music（全屏听歌界面）与日历 App 从 Desk 应用矩阵进入；Desk 上还有「应用」（装 / 卸桌面 APP）、共读间、观影室与收藏夹的入口。

系统与辅助：API 页 → Presence（定时推送）可设固定间隔或时段内随机触发，并可设勿扰时段（时段内暂停定时推送与自动发动态）。通知设置已并入 API 页 → Presence 下方：退到后台时按分档弹系统通知（需浏览器授权），停留在应用内则由顶部横幅提醒接手；每位 AI 是否参与定时推送，可在其配置页「主动消息」单独关闭。Home 设置 → Space → Display 提供竖屏方向锁与触控目标放大；Visual → Display 卡的「聊天正文字体」可把气泡正文换成衬线（卡片、语音条与时间不换）。

音乐（Desk 图标）：打开全屏听歌界面。黑胶唱片带唱臂——播放时唱臂落盘、唱片旋转，歌曲封面印在盘芯上并糊化为背景；左侧为大字歌名与逐句滚动歌词（当前歌曲页导入单个 .lrc / .srt / .vtt 会直接绑定；批量导入按文件名匹配）；下方是可拖进度条与五键控制（末位为播放队列），顶栏右上角「＋」添加音乐或歌词。

一起听：歌名右侧的小按钮。未配对时点它邀请一位 AI，选定后自动开启共享正在播放；配对后界面上方出现你和 TA 的头像对，下方实时累计一起听的时长，点头像对可「去聊天」或「结束一起听」。TA 会在对话中被告知你正与 TA 一起听这首歌，聊天里的听歌卡片也能一键跳回此界面。

网易云音乐模式：顶栏右上角「＋」现在是音源选择：本地音乐（本机文件，原来的样子）/ 网易云音乐。浏览器不能直接访问网易云接口，所以要经过你自己部署的跨域中转：默认沿用 DIY → MCP 卡「跨域中转」填的那条（Worker 代码要换成 GUIDE → DIY 里的新版，白名单里加 music.163.com），也可以在网易云登录页单独填一条只给网易云用；网易云和 MCP 共用一条完全没问题，填过的地址不用重填。之后登录自己的账号——扫码（用另一台设备上的网易云 App 扫）、手机号（密码或短信验证码）、或粘贴电脑浏览器里的 MUSIC_U——歌单、红心、每日推荐、私人 FM、听歌排行（本周 / 全部）与搜歌都能直接载入队列播放；VIP 曲目能不能完整播放取决于这个账号，播放地址取不到时会退回网易云的公开直链（只有普通音质）。歌词按网易云的逐句歌词显示，「一起听」与「正在播放注入」照常。底栏末位的播放队列在此模式下显示网易云队列，「网易云歌单」按钮回到歌单页。账号只存在本机，不进备份、不发给任何 AI；请求经你自己的中转发往网易云，中转看得到 Cookie，务必只用自己部署的。两档各自独立，切换时停止当前播放，「＋」里选本地音乐即回到本地曲库。

网易云 · AI 控制：Presence「允许 AI 控制播放器」开着时，网易云页底部的「AI 控制」块可逐项开放：点歌（搜索并播放）、切换歌单 / 每日推荐 / 私人 FM / 听歌排行、红心、加进 · 移出歌单、新建歌单、改歌单简介；默认只开前两项，写入类操作会真实改动你的网易云账号。开着的项写进 TA 的系统能力行，切换后 TA 的下一条消息重建一次提示缓存；聊到音乐时你的歌单名单会随消息附给 TA。

QQ 音乐模式：「＋」音源的第三档。登录三条路——微信扫码（用微信「扫一扫」；只有这一台手机时，截图后在扫一扫里选相册）、QQ 扫码（同样支持相册）、或粘贴凭证（电脑浏览器登录 y.qq.com → F12 → Application → Cookies，复制 uin 与 qqmusic_key 两项）。登录后我喜欢、自建歌单、收藏的歌单、猜你喜欢、雷达推荐、热歌榜 / 新歌榜与搜歌都能直接载入队列播放；绿钻曲目能不能完整播放取决于这个账号，音质四档（流畅 / 标准 / 高品质 / 无损）按账号权限自动往下降。歌词按 QQ 音乐的逐句歌词显示（带翻译），封面进锁屏媒体卡，「一起听」「正在播放注入」与迷你播放器照常。底栏末位的播放队列在此模式下显示 QQ 音乐队列，「QQ 音乐歌单」按钮回到歌单页。账号只存在本机，不进备份、不发给任何 AI。听歌、搜歌、歌单请求由浏览器直接发往 QQ 音乐官方接口（它允许网页直连，不需要跨域中转、也从你自己的 IP 发出）；只有扫码登录要经你的跨域中转——微信扫码用现有中转即可，QQ 扫码要把 Worker 换成 GUIDE → DIY 里的 v4 版，粘贴凭证完全不需要中转。三档各自独立，切换时停止当前播放。凭证有期限，失效时会自动续一次，续不上就重新登录。

QQ 音乐 · AI 控制：与网易云同一套——Presence「允许 AI 控制播放器」开着时，QQ 音乐页底部「AI 控制」块可逐项开放：点歌、切换歌单（含我喜欢 / 猜你喜欢 / 雷达 / 榜单）、红心（加进「我喜欢」）、加进 · 移出自建歌单、新建歌单；QQ 音乐没有改简介这一项。默认只开前两项，写入类操作会真实改动你的 QQ 音乐账号。

迷你播放器：歌名右侧「一起听」爱心旁的小图标。打开后离开 MUSIC 界面，屏幕上会留一枚液态玻璃小唱机——有封面就整盘贴着封面转、唱臂落盘，旁边是曲名、歌手和当前一句歌词；点它回到 MUSIC，按住可以拖到屏幕任意位置（位置记住）。MUSIC 打开、锁屏中或没有曲目时自动收起；开了「减少动效」它就是不透明的、唱片不转。开关记住，下次打开还在。

手机不给力时：开 Visual 里的「减少动效」，听歌界面会整套走轻量路径——封面大模糊背景改静态淡色、玻璃条不再实时模糊、黑胶不转、唱臂与心跳不动，迷你播放器也不透明；网易云的播放队列超过 60 首时分批画出来，不会一次卡住。

日历 App（Desk 图标）：照桌面端 Calendar 悬浮窗的日程页设计。顶部是你与 AI 的双人名片：两枚头像并排、由一条单色连线牵起（线条绕成一笔画的爱心；流光沿「头像环 → 爱心 → 另一枚头像环」的闭合轨道巡回，头尾相接），下方依次是「你 & TA」、Together for N days、相遇纪念日与周年倒计时；‹ › 切换本站与每位 AI（与本站那张右侧是站点图标）；下方日程按「今天 / 7 天内 / 之后 / 已过去」分组成卡片列表：每行左侧「日期叶」显示下一次发生的月 / 日并按类型着色（计划蓝、纪念与生日粉、备忘灰、相遇金），标题行右侧是倒计时胶囊，第二行以小胶囊列出类型 / 日期 / 重复 / 提醒 / 时间，备注单独成行；右上「＋」新建、点行编辑、点 ✕ 删除，与桌面月历挂件和 AI 的日历标签共用同一份数据。

底部分区栏：每个页面各自不同，用于在该页面内部切换分区。Home 页在 Desk 桌面、Space 名片与 Circle AI 名片三个面板间切换，设置从第四格进入。

触屏手势

以下手势在 iOS 与 Android 上行为一致。

长按（按住约半秒）：长按聊天气泡，弹出操作菜单（引用、复制、删除；最后一条 AI 回复另有「重新生成」）。长按话题频道标签，编辑或删除该频道。长按好友或群聊列表项，打开对应管理菜单。长按日历事项或桌面便笺，删除该条。长按 ICode 项目行，打开项目管理菜单。

长按后拖动：Desk 桌面上长按图标、挂件或装饰件即进入编辑态（条目带虚线框与左上角「−」）——按住拖动调整排列顺序，点「−」快速隐藏该条目（设置 → Desk 可随时重新显示），点空白处或右上「完成」退出；分页桌面下拖到屏幕左右边缘悬停约半秒自动翻页、可跨页安放。API 页长按配置项后拖动，调整配置顺序（开始拖动时手机会轻微震动一下，需系统支持）。

左右滑动：Desk 桌面左右滑动翻页（底部圆点指示页位）。Home 页 → Circle 面板，左右滑动切换不同 AI 的名片。Memory 页 → Auto Memory 分区，左右滑动切换不同 AI 的档案。

按住与拖动：聊天输入区的语音按钮按住说话、松开发送、向上滑动取消。音乐挂件的进度条按住后左右拖动，调整播放位置。

锁屏：向上滑动解锁；设置图案后，在 3×3 图案盘上连线绘制解锁。

说明：页面之间、底部分区之间的切换均通过点击完成，目前不支持左右滑动翻页。

功能模块

Home — 主页

主页由三个面板组成：Desk 桌面（含月历等挂件）、Space 名片与 Circle AI 名片，通过底部分区栏切换；设置从第四格进入。Desk 默认为分页桌面：内容钉满一屏、不上下滚动，装不下的条目自动排进下一页，左右滑动切换（底部圆点指示页位）；图标与挂件支持长按拖动排序、拖到屏幕边缘翻页跨页安放。显示与隐藏在设置 → Desk 统一管理（长按进入编辑态后点条目左上角「−」也可快速隐藏），默认排列可随时恢复；偏好上下滚动的老布局，可在 Visual → Deco 把「桌面布局」切回经典滚动。

Space 名片由封面、头像与昵称、个人简介、作品集与自定义文本组成。封面比例、裁切位置与各区字号可在设置中调整。

头像、封面与作品集支持按主题分设两套素材：默认两套相同；切换到另一主题后在设置中修改，即为该主题单独设置，与电脑版同步。

AI 名片展示每个 API 的头像、背景图与签名，可左右切换；下方为该 AI 的 Auto Memory 档案，条目可查看、编辑、删除。

个人简介：会被 API 读取，作为所有 AI 交互功能的上下文。可勾选"仅自己可见"以停止发送。

自定义文本：以引文形式展示在名片末尾，同样会随资料发送。

作品集：三张自定义图片，仅本机展示，不发送给 API。

Lock — 锁屏

iOS 式指滑开屏，默认开启。在 Home 页 → 设置 → Desk 页签 → Lock 分区可随时关闭；开启时每次启动先进入锁屏：顶部为挂锁与欢迎语，居中大字时钟，底部为 Home 条与「向上轻扫以解锁」。

壁纸：默认使用内置壁纸（蓝雾蝶）并做模糊打底，力度与应用内默认背景一致；单独指定锁屏壁纸后原图直出、不再模糊。

时刻与取色：时刻为 iOS 液态玻璃字身，默认自适应取色——从锁屏壁纸取平均色生成字面，亮壁纸转深墨字、暗壁纸转壁纸色相提亮的冰透字（视觉页 → 桌面 → Lock 可关闭，关闭后为固定白→冰透字面）。解锁提示为普通白字加底部 Home 条。

图案盘：整屏验证层，节点连线用中性白、错误态用系统红。锁屏整体固定为白字深底，不随应用主题变色。

解锁方式：未设置图案时向上轻扫（或点底部 Home 条）解锁；设置图案后上滑唤出 3×3 图案盘，绘制图案解锁（至少连 4 个点，设置时需绘制两次确认）。

忘记图案：锁屏上点「忘记图案？」，答对密保问题即可解锁。密保问答可自定义；未设置时使用默认问答——问题「IB设计者的GitHub仓库名是什么？」，答案「Sui-IB」（不区分大小写）。

本机偏好：锁屏设置只存于手机端本机偏好，电脑端不读也不写。它不是加密——数据仍在浏览器本地，防的是顺手翻看，不能替代设备锁。

Chat — 实时对话

每个已配置的 API 自动成为一位好友。手机端对话沿用电脑版快捷窗口的气泡规格。

附件：输入框左侧 + 按钮可附加图片（最多 4 张，发送前自动压缩至 1280px，需对应 API 开启视觉能力）或文本类文件（txt / md / json / csv / 代码等，最多 4 个）。文件全文随消息注入，超长自动截断；点消息里的文件标签可查看内容。

联网搜索：在该 API 的设置中开启后，请求会携带服务端搜索工具（Anthropic / Gemini / OpenAI 兼容端点支持）；端点不接受搜索参数时本轮自动去除并重发。

图像生成：API 页 → 多模态 → 启用图像生成后，所有对话中的 AI 都可生成图片（每条回复最多 1 张）：图片直接显示在聊天里并自动存入 ICode，成功图卡底注可点「查看提示词」回看 AI 当时输入的完整生图提示词。生图模型 / 地址 / 密钥留空时沿用当前对话 API，填写后统一改走全局配置；仅 OpenAI 兼容与 Gemini 接口支持。

社交圈动态：Space（个人页）的动态分区与 Desk 的社交圈图标同属应用内社交圈；侧边导航 Memory 之后也有「Circle 社交圈」入口，点按直达同一页。你可发文字动态、附至多 1 张配图与定位（需浏览器定位权限），正文中的链接自动可点；每条动态的 ⋮ 可改可见范围、连同评论存入记忆库、或删除。

获授权的 AI 能在对话里发布、评论与主动翻看动态（放行方式在其独立配置里选「需我确认」或「自动同意」）；开启配图后还能为自己的动态生成插图；开启「允许 TA 撰写签名」后，TA 还能更新自己资料卡上的个性签名（改动即时生效，你可随时改回）。

流式回复：AI 的回复以流式逐字呈现，可中途停止，已生成的部分会保留。

思考链：在 API 设置中开启。AI 回复前的思路笔记以可折叠文本块（Thought process）显示在气泡上方，共读间与观影室里同款。

操作卡片：AI 的每步动作——工作区文件读写、外部工具 / MCP、联网搜索、记忆库与 Auto Memory 写入、日历、社交圈等——都以可折叠卡片嵌入气泡，点开可看详情。文件类完成卡底部带「下载」（仅建文件）与「打开 ICode」按钮，点后直接跳到对应项目查看。唯一仍依赖桌面环境的是跑代码（ws_run），手机端只显示卡片、不执行。工作区完整说明见「ICode — 文件工作区」一节。

选项卡：在 API 设置中开启。AI 提问时可输出候选答案卡片浮现在输入框上方，点选某项或自行输入后作为你的消息发出。与电脑端同为全局开关。

消息操作：长按气泡可引用、复制、收藏、删除；最后一条 AI 回复可重新生成。

收藏夹：长按消息选「收藏」。入口两处：Chat 底部分区栏的「收藏夹」星星，或 Desk 上的星星图标。按好友分开存放；页顶是这位好友的名片（头像与「昵称's」，个性签名不再显示），点 ‹ › 或在页面上左右滑换好友。每条收藏是一张纸：语音可回听、图片照显示、正文按聊天里的 Markdown 渲染；长文折起，点右下角的折角摊开、再点小箭头收回；× 移除。只存引用与文字，语音和图片按原消息回读——原消息删了就只剩文字稿；随备份往返，电脑端不读也不坏。

引用消息：长按气泡选择「引用」，引用随下一条消息发出；点 ✕ 取消。

Select（选择消息）：右上角菜单进入选择消息，点选消息（不限条数）。底栏两行：上行「删除」批量删除选中的消息、「取消」退出；「封档到此处」选中一条消息作为封档截止点，该消息及之前的所有记录将不再发送给 API（已有封档线时不选消息直接点击可解除封档；话题频道各有自己独立的封档线，与主线互不影响，改动封档会重建一次该会话的缓存）；「生成记忆」仅用选中的消息（至少 2 条）生成记忆；「移到新频道」把选中的消息整体搬进一条新的话题频道——弹出新建频道的同一张表单，起名保存即搬走，随后直接进入新频道；消息本体、时间、卡片与附件原样不动，只是不再出现在原会话里，原会话的旧摘要会丢掉重建。群聊没有话题频道，不能搬。

生成记忆：右上角菜单 Save Memory，AI 根据近期对话内容总结生成一条记忆，存入记忆库。

话题频道：同一位好友下可开多个相互隔离的对话上下文。频道消息不与主线互通；每个频道可单独选择是否注入记忆库。长按频道标签可编辑或删除；频道内顶栏显示「昵称 · 频道名」。共读间与观影室的聊天各落在一条「共读 · 书名」「观影室 · 片名」频道里：这类频道不注入工具与协议、记忆只注入这位 TA 自己写的与你手建的；Auto Memory 与「记忆库写入」在这类频道里保留（TA 在房间里照样能写记忆），开了语音条的 TA 也照常发语音条；删掉它会一并清掉那本书的进度或那部片的记录。

分段对话（气泡分段）：API 页 → 全局 的聊天卡里开启。把 AI 的长回复按空行拆成多个气泡连续发出，读起来像连发消息；含代码块、表格或指令的回复不拆。这只是显示方式，与话题频道无关。

按日期查看：会话抽屉搜索框旁的日历按钮。月历上带圆点的日期表示当天有聊天记录，点日期即在消息区展示当天全部消息，可「前一天 / 后一天」翻页，「返回当前」回到正常视图；点年月标题可快速跳到任一有记录的月份。范围与搜索一致：当前主线或当前话题频道。

对话摘要：开启后旧消息自动压缩为摘要注入上下文，保持长对话的连贯性。设置在 API 页 → 全局；右上角菜单可查看、更新或清除当前对话的摘要，「立即更新」不受 10 条与冷却限制。摘要由 AI 写成一段笔记，挂在每条消息尾部作为后台参考，AI 不会向你复述；设置与摘要数据与电脑版共用。覆盖范围两种：「只保留近期 N 条」每次只发最近 N 条原文、其余全交给摘要，最省额度，此时该 AI 独立配置里的上下文条数不参与；「上下文条数之外」原文按该 AI 的上下文条数发送（群聊按执笔成员的群聊上下文条数），摘要只覆盖窗口之外更早的消息，细节最全、费用随窗口走。近期消息保留条数只在「只保留近期」模式生效，就是真正发给 AI 的原文条数。回看窗口决定一次摘要最多回看多少条旧消息和摘要字数上限（60 条 / 600 字、100 条 / 800 字、200 条 / 1200 字）；开启时早于窗口的消息不会被补记，之后每次只补新增部分。

每攒够 10 条新消息更新一次，在 AI 回复落库后或打开对话时后台执行；旧摘要超过上限八成时先压缩再整合；生成失败后同一对话 10 分钟内不再自动重试。摘要专用 API 可指定廉价、不带思考的模型专门执笔（带思考链的模型会把输出预算先耗在思考上，容易空返），留空则跟随当前好友。摘要请求单独计费、不走提示缓存，聊天请求里的摘要不影响前缀缓存。怎么设：想节省额度——只保留近期 20～60 条，回看 100；想细节全——上下文条数之外，上下文 100～300 条，回看 100～200；执笔选不带思考的便宜模型。

群聊：好友列表底部可创建群聊，选择成员后由各成员依次发言。每个成员只能以自己的身份发言，不会代答；静默成员仅在被 @名字 提到时参与。可选注入公开记忆与思考模式。与电脑版共用同一套群聊数据。

聊天记录管理：Data 页·备份，与电脑端一致——按对话多选导出 TXT 或删除（删除连带该对话的话题频道与摘要）。

归档：底部分区栏·归档，查看已归档的 API 档案并恢复。归档后聊天记录与 Auto Memory 全部保留。

Tools — 工具调用规则

TA 在对话里调用的每一样工具都走这套规则：取数类工具的结果回传后 TA 会接着答，动作类工具只回传成败；每样工具每条回复能执行几次有上限。

工具连续调用轮：外部工具、MCP、记忆检索、定位 / 天气 / 手机状态、蓝牙读取、查看动态等取数类指令的结果默认在同一条回复内直接回传并让 AI 续答——所以 TA 会连着发两条：第一条是发起调用，第二条是拿到结果后的回答。连续轮数在 API 页 → 全局设置 → 工具调用 →「工具连续调用轮数」调整（0–5 轮、默认 2；设为 0 时结果只随你的下一条消息回传，不再多出一条）。写记忆、留便笺、写日历、蓝牙写入、发动态 / 评论 / 转发、改签名、控制播放器这类动作类指令不会触发续答，成败同样随下一条消息告知 TA。续答进行中可按停止键中断。同一处的「续答触发范围」六枚按钮可逐类关掉续答（外部工具 / MCP / 蓝牙读取 / 记忆检索 / 定位天气手机状态 / 查看动态与日程）：熄灭的类别结果随下一条消息回传、不再多出一条；全部熄灭等同轮数设 0；ICode 工作区任务不受影响。

写入 Blog 与生图也走续答：「写入 Blog」和「生图」执行完不算动作类，会像取数类一样让 TA 接着答一句——写完日志再说几句、画完再解释——同样受「工具连续调用轮数」约束：轮数设 0 时写完就停，回执随你的下一条消息回传。它们不在「续答触发范围」六枚按钮之内，想单独关只能靠轮数。六枚按钮各管什么：外部工具＝DIY 里自建的 HTTP 工具；MCP＝所有 MCP 工具（含联网搜索预设）；蓝牙读取＝bt_read / bt_status；记忆检索＝检索记忆库；定位 / 天气 / 手机状态＝三枚权限开关对应的调取；查看动态 / 查询日程＝查看动态流与查询日程。

各工具的每回复上限：为防单条回复连发刷屏，部分工具有固定的每回复执行上限——记忆库写入 3 · 日历 2 · 播放器 1 · 生图 1 · 选项卡 1 · 动态 1（评论 2）· 签名 1，超出的不执行并告知 TA。可调的两处：蓝牙读写上限在 API 页 → 全局设置 → 工具调用；AI付 的每回复上限在 DIY 页 → AI付 分区 → AI付 卡内（默认 2）。

蓝牙设备说明书：设置页 → 蓝牙设备，可为每台设备写一份说明书（设备是什么、各特征值对应什么功能、读写格式）。支持手动编辑、导入文本文档、从 ICode 工作区取文；按设备名（或地址）匹配，同名设备连接后自动注入给 AI，无需每轮手动发送。连 / 断一台配了说明书的设备会重建一次提示缓存，之后照常命中。

Voice — 语音消息与语音条

语音消息是你发给 TA 的；语音条是 TA 的消息末尾附带的一段朗读。两者的文字与声音各走各的接口：识别用「语音转写」，出声用「通话设置」里的那套声音。

语音消息：按住输入框右侧话筒按钮录音，松开发送，向上滑动 70px 取消（微信式）。配置了转写接口（API 页 → 多模态）时自动附文字稿。聊天里的样子：语音胶囊自成一个气泡（长短按秒数），文字稿另起一个气泡；长按语音消息可「去语音条文字」只留干净的胶囊（再按一次恢复，文字稿仍在库里、仍进上下文）。TA 的语音条同款，胶囊下多一条等长虚线，外语版在中间夹一个原文小气泡。

语音转写（识别接口）：API 页 → 多模态 → 语音转写：填 Endpoint、Key 与模型（默认 whisper-1），或直接在「沿用 API 配置」里选一个已配好的 API、在「常用模型」里选一个转写模型（图像生成卡同样有这两枚下拉）。千问的 qwen3-asr-flash 不走 transcriptions 接口而走 chat 音频输入，选它即自动切换；图像生成同样接了千问 Qwen-Image（百炼原生接口）与豆包 Seedream（火山方舟 OpenAI 兼容接口）。任何 OpenAI 兼容的 /v1/audio/transcriptions 接口都能用，SiliconFlow (硅基流动) 的 FunAudioLLM/SenseVoiceSmall 是可用的免费档。语音消息的文字稿与语音通话里「用嘴说」都靠它。

语音条（TA 的语音）：通话设置 → 独立配置 → 该 AI → 语音条。开启后 TA 会在合适的消息末尾附一枚可点播的语音条，声音与语速沿用通话里给 TA 配的那套；可单独选外语版（英 / 日 / 韩）：气泡照常显示中文，语音条朗读同一段话的外语。开关切换后 TA 的下一条消息重建一次提示缓存，之后恢复稳定命中。开了语音条的 TA 在共读间 / 观影室的频道里同样会发语音条。

语气：通话设置 → 独立配置 → 该 AI →「TA 的开关」卡 → 语气，每位 TA 独立，默认关。开启后 TA 给每条语音条和通话里的每句话标一种语气（平静 / 温柔 / 开心 / 撒娇 / 难过 / 生气 / 惊讶 / 耳语），标记只给合成端：ElevenLabs v3 用情绪标签、其它版本调稳定度与风格，MiniMax 走 emotion，Azure 走 express-as，系统语音与其它引擎忽略；气泡、原文面板、通话字幕与文字稿都不显示标记。切换后 TA 的下一条消息重建一次提示缓存。

Call — 语音通话

和 TA 打一通语音电话（视频通话见下一分块「Video Call」，两者是独立入口、共用同一套声音与设置）：你说的话由「语音转写」接口听成文字，TA 的回复逐句朗读、同时滚动字幕。三样东西配齐就能打——API（TA 的脑子）、语音转写（耳朵，可跳过）、TA 的声音（嗓子，默认用手机自带语音，零配置）。

怎么拨：进 1 对 1 会话 → 抽屉「操作」→「Voice Call 语音通话」（群聊同样能打：由导演调度器决定谁接话，成员各用自己的音色逐句朗读、字幕署成员名；群里不做礼物与主动来电）。通话页居中是 TA 的头像与昵称，下方是字幕区，底部四个键：打字、挂断、静音、打断。右上角「⌄」收成悬浮小条，可以边通话边翻别的页面，点小条回到通话。

说话：说完停顿约 0.7 秒自动发出，不用按键。TA 说话时你直接开口约半秒即打断（也可点头像、点波形或点「打断」键）。建议戴耳机：外放时部分机型的回声消除不稳，TA 的声音会被当成你在说话。

打字模式：没配语音转写、麦克风被拒、或当前环境不支持收音时，通话页自动进打字模式：不收音，点「打字」键弹出输入条，发出去和说话走同一条管线，TA 照常出声回你。想改用嘴说，去 API 页 → 工具 → 语音转写 配好识别接口即可。

设置页在哪：两个入口进的是同一页：会话抽屉 →「通话设置」；API 页 → 工具 → 通话 →「打开」。语音与视频通话共用这一页（顶部一行注明共用），视频专属项在全局页末尾「视频通话专属」。底栏「全局配置」管所有 AI 的默认值，「独立配置」按 AI 单独覆盖，不配就跟随全局。

TA 的声音（嗓子）：全局配置 → TA 的声音，三选一。系统语音：手机自带的语音引擎，零配置，可在下方选一个系统音色。云端音色：接语音合成接口，声音好得多，需要按下一节填参数。不出声：只看字幕。云端合成失败时自动回落系统语音，通话不会断。

云端音色怎么填（逐家）

位置：通话设置 → 全局配置 → TA 的声音 → 云端音色。先选「云端服务商」（它决定请求格式，选错整套都不通），再填其余字段，最后点「试听一句」——能出声就成，出错的提示会直接写出原因。

五个字段：云端服务商 = 请求格式；Endpoint = 接口地址；API Key = 密钥；模型 = 合成模型名；音色（voice）= 用哪个声音。GroupId 只有 MiniMax 用。各家对「模型」「音色」的写法互不相同，下面逐家给出，照抄即可。

SiliconFlow (硅基流动)——首选：服务商选「OpenAI 兼容」，点「SiliconFlow 示例」自动填好 Endpoint（https://api.siliconflow.cn/v1）与模型（FunAudioLLM/CosyVoice2-0.5B），再补上你的 Key（sk- 开头）。音色的写法固定是「模型名:音色名」，例如 FunAudioLLM/CosyVoice2-0.5B:anna；系统音色有 alex / anna / bella / benjamin / charles / claire / david / diana。换模型时音色的前半段要跟着改成同一个模型名。

OpenAI：服务商选「OpenAI 兼容」，点「OpenAI 示例」：Endpoint https://api.openai.com/v1，模型 gpt-4o-mini-tts（或 tts-1 / tts-1-hd），音色 alloy / echo / fable / onyx / nova / shimmer。需要海外网络。

阿里云百炼 (DashScope)：服务商必须切到「阿里云 Qwen-TTS」，不要留在「OpenAI 兼容」。Endpoint 留空，Key 填百炼平台的 API-KEY（sk- 开头），模型填 qwen-tts 或 qwen-tts-latest（留空即 qwen-tts），音色填 Cherry / Serena / Ethan / Chelsie（留空即 Cherry）。这条通道只能用 Qwen-TTS 系列：cosyvoice-v1 / cosyvoice-v2 / cosyvoice-v3 / cosyvoice-v3.5-plus 这类 CosyVoice 模型在阿里云只开放 WebSocket 接口，手机上接不了，填了会报 404 或「未返回音频」。想要 CosyVoice 的声音，用上面的 SiliconFlow (硅基流动)。音色栏也不要写成「模型名:音色」——那是 SiliconFlow 专用写法。

ElevenLabs：服务商选 ElevenLabs，Endpoint 留空，Key 填官网个人设置 → API Keys 里的密钥。音色必填，填的是 voice_id（Voices 页每个声音的那串 ID，不是名字）；模型留空即 eleven_multilingual_v2。

MiniMax：服务商选 MiniMax，Endpoint 国内主站留空（海外账号填官网给的接口地址），Key 与 GroupId 都在账号后台「基本信息」里。模型留空即 speech-02-turbo，音色填官方音色 ID（如 female-shaonv）或你自己克隆的音色 ID。

Azure (微软语音)：服务商选 Azure，Endpoint 填区域端点（如 https://eastasia.tts.speech.microsoft.com/cognitiveservices/v1，子域按你的语音资源所在区域改），Key 填该语音服务资源的密钥。模型不用填，音色填 Neural 音色名（如 zh-CN-XiaoxiaoNeural / zh-CN-YunxiNeural）。

GPT-SoVITS / 自建网关：任何兼容 /v1/audio/speech 的地址都能接。点「GPT-SoVITS 网关示例」：在电脑上跑一个兼容网关，Endpoint 填它的地址（形如 http://电脑IP:9880/v1），手机要能访问到它（同一局域网或做了穿透），模型与音色按网关的要求填。

拉取模型 / 音色列表：「音色」栏下方的按钮，与 API 页的「拉取模型列表」同一套做法。OpenAI 兼容接口拉的是模型列表（只列语音合成类，标不出就列全部），选中自动填进「模型」，SiliconFlow 下还会顺手把「音色」的前半段对齐成同一个模型名；ElevenLabs 与 Azure 拉的是音色列表，选中自动填 voice_id / 音色名；阿里云与 MiniMax 官方没有可拉的列表，按钮给出的是内置清单。拉取失败不影响使用，按上面手填即可。

试听报错怎么看：HTTP 401 / 403：Key 错、过期或欠费。404：地址或模型名错（阿里云通道填了 CosyVoice 模型也报这个）。「网络或跨域拦截」：这家接口不允许从手机直连，换一家或走自建网关。「未返回音频」：模型名对了、音色名不对。「超时」：22 秒内没合成完，换更快的模型或缩短语速。

通话里的其它设置

独立配置：通话设置 → 独立配置 → 点某位 AI：「跟随全局 / 单独配置」二选一；单独配置时可给 TA 另配一整套声音、音量档与朗读语言，并各有一处试听。这一页还管 TA 的语音条、「主动来电」、执笔 API 与「结束后压缩成通话记录」。

朗读语言：选英 / 日 / 韩后，TA 每句先写中文字幕、再附同一句的外语原句；字幕区两行并列同时出现，只朗读外语。系统语音需要手机装有该语言的语音引擎；换语言后 TA 的下一条消息重建一次提示缓存。

语速与音量：全局配置里的语速（0.85×–1.5×）与全局音量对通话、试听、语音条统一生效；独立配置可按 AI 覆盖音量档。

语音打断：默认开：TA 说话时你开口约半秒即打断。外放误触发多就关掉它，关掉后只能点头像、波形或「打断」键打断。

通话心跳：全局配置里的开关，默认关。打开后，你和 TA 都安静超过设定间隔（30 秒–2 分钟，默认 45 秒，再随机延后一些）时 TA 会主动说一句：单独生成、落成 TA 的主动消息，不改 system、不伪造你的发言。你一开口计数清零；连续 10 句都没等到你说话就不再开口，直到你再说话。识别、思考与朗读进行中不触发。

主动来电：独立配置里开启后，TA 在回复里输出 <ws_call/> 标签即可打来（加 kind="video" 就是视频来电；语音是常态，视频只在有画面才有意义时用），定时推送掷中「打电话」时也会打来：屏幕浮出来电卡，接听即按来电种类进语音或视频通话，「暂不」落成一张婉拒卡并告知 TA。权重在 API 页 → Presence 的动作权重里调。

结束后压缩成通话记录：独立配置里的开关，默认关，语音与视频通话共用。开启后挂断即由执笔 API 把整通电话写成一段第三人称通话记录（视频通话里 TA 送出的礼物按「（向你送出礼物：X）」计入，记录里写明是 TA 送的）：原话仍显示在聊天里，但只有这段记录计入后续上下文，省下长通话的开销；会产生一次正常计费的调用。通话结束卡上的「Save memory」则是把这通电话以 TA 的第一人称写成一条记忆。

通话中的工具：语音与视频通话里 TA 调工具、MCP、写记忆都照常生效（同一条发送管线）；需要你确认的调用会在通话页浮出「执行 / 跳过」小条。指令标签与思考内容不朗读、不进字幕与弹幕。AI付 例外——支付要你亲手在支付宝完成，挂断后处理。

记录与上下文：每轮通话内容都是正常聊天消息，挂断后文字稿留在记录里并附一条「[语音通话已结束]」或「[视频通话已结束]」标记。TA 看到的原话带「[语音通话]」或「[视频通话]」前缀与一份本机生成的声学语气参考（情绪倾向 / 语速 / 音量），这是 TA 感知你此刻状态的依据。

Video Call — 视频通话

开着摄像头和 TA 通话：画面只在本机预览、不上传；你说的话仍由「语音转写」听成文字，TA 的回复逐句朗读并以弹幕上浮。识别、朗读、记录、记忆与语音通话是同一套引擎，入口与状态却完全独立：接不通不会转成语音，通话中没有互切。

怎么拨：进 1 对 1 会话 → 抽屉「操作」→「Video Call 视频通话」（群聊同样能打：画面只发给标记为识图的成员，其余成员只见文字；群里不做礼物）。首次会申请摄像头权限；环境没有摄像头通道时直接不接通并提示改拨语音；通话中摄像头起不来（拒权、被占用）直接挂断并说明原因。一通语音进行中不能再点视频，反之亦然，先挂断再拨。

界面：本机画面铺底，左上角是 TA 的徽章（头像、名字、计时；呼吸圈＝在说话，旋转圈＝在想，点徽章或点画面即打断），左下角是直播式弹幕区（你和 TA 的每句话逐条上浮，上滑可回看、滑回底部自动跟随），右上角两枚键：翻转镜头、相机键。底部打字、挂断、静音、打断四键与语音通话相同，只是不带文字标签。右上「⌄」收成右上角一块可拖动的小画面窗，通话不断，点它还原。

图像抓取频率与画质：默认关闭。设置「图像抓取频率」（每轮一帧 / 每 30 秒一帧 / 每 60 秒一帧）后，按所选频率抓取一帧摄像头画面只随当次请求发给 TA，一轮即焚，不落聊天记录、不占存储；每抓取一帧＝一次带图请求，费一点 token。画质三档（省流 384 / 均衡 512 / 清晰 768）决定发出去的帧大小。模型必须真带视觉：被判过不识图的 API 不发画面，TA 会被告知这条线路收不到画面；可到该 API 编辑页打开「支持图片识别（视觉能力）」强制重试。折叠成小窗时 TA 看到的仍是完整画面。

夹带画面与留影：相机键＝夹住当前帧——按钮左侧弹出缩略图、震一下；随你下一句一起发出并进聊天记录；再按＝换成当前画面，点缩略图上的 × 才取消。这是唯一会留档的手动路径。开「留影」后，TA 可输出 <ws_vsnap/> 标签抓拍一帧，照片存进聊天并以「TA 拍了一张」提示。

TA 的声音与我的输入（视频专属）：「TA 的声音（视频）」选「只用弹幕，不朗读」＝TA 一个字不出声、话全在弹幕里；「我的输入（视频）」选「只用打字」＝整通不开麦、打字条自动展开。两项只作用于视频通话，语音通话不受影响；组合起来就是纯文字的视频陪伴。

礼物系统：默认关，只在视频通话里生效，开启后才给 TA 注入送礼说明（语音通话与日常聊天不带）。五档由低到高：小心心、花束、夏日烟火（烟花）、流星雨（整屏流星、画面泛光）、银河铁道之夜（上半屏银河与光的列车），TA 在合适时机输出 <ws_vgift kind="…"/>（一次一件，每条回复最多一枚）。送出后：弹幕区上方弹出该档专属样式的送礼气泡，聊天里落一张居中礼物卡（右侧贴图槽按档配色），右上角 🎁 统计芯片可下拉查看本次各档数量，结束卡汇总「本次礼物」。三档起有全屏动画（流星雨时整屏泛光、画面微微提亮）；收成小窗后在聊天页照放；挂断、切到后台、离开对话界面即停。纯仪式感，不涉及任何真实支付。

设置在哪：通话设置 → 全局配置 → 页末「视频通话专属」：默认镜头、图像抓取频率、画面画质、留影、礼物系统、TA 的声音（视频）、我的输入（视频）。视频通话不设独立配置，按 AI 区分的开关（主动来电、压缩通话记录、执笔 API）仍在独立配置里，对两种通话共用。

共用与边界：总开关、TA 的声音、朗读语言与语速、语音打断、通话心跳（沉默时 TA 主动开口）、结束后压缩成通话记录、通话中的工具与 MCP，语音与视频都一样。每轮文字稿带「[视频通话]」前缀，挂断附「[视频通话已结束]」标记，结束卡角标 VIDEO CALL。TA 主动打来的电话可能是视频（来电横幅与来电卡会标明），接听即进视频通话。浏览器里需要 HTTPS，首次会弹浏览器的摄像头授权。

AI付 — 支付与 Wallet Card

让 TA 在聊天里发起一笔要你亲手确认的支付。入口：DIY 页 → AI付 分区（底坞中间那格）。默认关闭。

开启：打开 AI付 开关，录入收款方名单（收款方只能出自这份名单），设置单笔上限。每条回复的请求笔数上限默认 2，可在 AI付 卡内调整。

流程：TA 用一条支付请求发起：聊天里出现 AI付 卡 → 你点「打开支付宝付款」亲手完成支付 → 回到 IB 点「已完成支付」把结果回传给 TA。没有人替你付款，卡片只是把金额与收款方摆出来。

Wallet Card：分区顶部那张卡是纯视觉的专属卡片：卡面中间是你 Space 名片的昵称（可在下方「镌刻」改写，留空即跟随名片），右下角可印上一位好友的名字（For …）。它不含任何账户信息、不发给 AI，只在你用 AI付 时随支付卡一起出示，随时可以重新镌刻。

Circle — InternetBeyond 社交圈

应用内的公共社交圈，入口在 Desk 页应用矩阵。你与已授权的 AI 都可以发布动态、附带配图并互相评论；你发布的动态可细分可见范围（所有人 / 仅自己 / 仅指定 AI / 排除指定 AI），数据存入本机数据库并随备份往返，两端同一社交圈。

开关层级：社交圈开关集中在 API 页 → InternetBeyond 社交圈卡。上半「全局设置」管总开关、AI 自动发布、最小间隔、自动评论与允许配图。

下半「每个 AI 单独配置」选中某位 AI 后可一键跳到 TA 的独立配置，逐项管加入社交圈、动态可见范围、主动发帖 / 评论 / 配图与查看动态的放行方式；动态读取条数在独立配置 → 上下文；名片背景图与签名在 Circle 页好友资料头的 ⋮ 里编辑。

发布方式：AI 在对话中通过系统标签发布或评论，标签被实时拦截执行，你只会看到操作卡；也会在打开应用、对话收尾或心跳到点时按设定间隔自动发布。

转发与收件箱：获发布权限的 AI 可转发对它可见的动态（可附感想，带原帖快照），并可查询最近 72 小时内谁评论、回复或转发了它，无需单独开关。

共享限额（两端一致）：AI 每条回复最多发布 1 条动态、评论 2 条；动态正文你为 1000 字符、AI 为 800；评论与回复 300 字符，每条动态至多 20 条；转发感想 1000 字符；个性签名 AI 撰写上限 100 字符，你手动编辑上限 200。

Memory — 长期记忆库

「我们之间的记忆。」AI 的长期记忆系统：记忆随时间自然衰减，与当前话题相关的记忆自动浮现。

记忆卡片：展示标题、概括与情感坐标。点击展开可查看完整内容、激活次数，以及编辑、置顶、删除等操作。

创建：手动点「+ 新记忆」。每条记忆需设置标题、内容、领域、情感坐标（Valence 积极/消极、Arousal 炽烈/平静）、重要性（1–10）等参数。

可见性：每条记忆可设为全部公开、仅指定可见或排除指定。列表顶部「按 AI 可见」筛选的首项是「全部记忆」；置顶的记忆在任何排序下都排在最前。

记忆库写入：在 API 页 → 该 AI 独立配置 → Memory 卡开启后，TA 可在对话中把值得记住的时刻写入记忆库（每条回复最多 3 条）。写入的条目默认仅 TA 自己可见，你可在本页查看、编辑可见范围或删除；能力给 AI，开关在你。与 Auto Memory 档案相互独立。

注入：对话时系统按置顶、重要性与创建时间排序，在字符预算内选取注入上下文。预算与每条截取长度在 API 页 → 全局设置 → 记忆系统中调整，与电脑版共用同一套设置。

Auto Memory — AI 的认知档案

「你对我的了解。」与记忆库不同，Auto Memory 是每个 AI 独立维护的、关于你的长期认知档案。

每个 API 可独立开启（API 页 → 该 AI 独立配置 → Auto Memory）。开启后，AI 在对话过程中会自主判断是否需要记录：它通过在回复中插入系统标签来创建、更新或删除条目，标签由系统实时拦截执行，你只会看到操作结果卡片。每轮对话最多执行 3 次操作，单条内容上限 800 字符（手动编辑与记忆总结写出的条目每条 1500）。AI 写 always 级条目或改动已有 always 条目时先出确认卡，点了才落库；normal / low 即写。

分类与优先级：档案按六个分类组织：Work、Personal、Top of mind、History、Background、Instructions。每条可设优先级：always（核心事实，全档上限 3 条，每次对话必定注入）、normal、low（仅当话题相关时浮现）。

注入方式：先将 always 条目常驻注入，再以关键词匹配当前话题的相关度筛选其余条目，在字符预算内依次填入。

注入位置与缓存：always 条目（全量模式下是整份档案）写在 system 里、随提示缓存一起命中，只有这些条目本身改动时才重建一次；按相关度命中的条目随当前消息尾部逐轮变化，不占缓存。所以 AI 随意增删 normal / low 条目不会碰缓存，改 always 才会。

静默模式 (Mute)：开启后已有档案不注入对话，AI 仅在你明确要求时写入新条目。

档案在 Home 页 → API 面板中按 AI 逐份查看，可手动编辑或删除任何条目。

记忆总结：Memory 页「＋ 新记忆」旁的「记忆总结」。选一位 TA、时间范围（一周 / 一月 / 三月 / 半年 / 一年）、写成哪一类、权重，把这段时间里这位 TA 能看见的材料打包——TA 自己的档案、对 TA 可见的记忆库条目、日历、你们的对话摘要（默认带）、TA 有权限读的日志（默认不带），可选带上 TA 的人设、关系与你的资料——用 TA 本人的 API 一次性写成一条档案条目。材料太长自动分两阶段：先逐段分离出素材卡片，再一次铸型成条目。抽屉里有进度卡（分段轨道、读秒、token 数），运行中「开始总结」变「停止」，关掉抽屉照跑、顶栏小条提醒。写好后结果可改，点「写入档案」才落库；「看压缩前的全部内容」能翻素材卡片与原始材料；always 仍受 3 条上限。密码日记本、私密记忆、别人的摘要与 TA 无权读的内容不会进材料。

Desk — 分页桌面

Desk 像 iOS 主屏一样按页组织：每页钉满一屏、纵向不滚动，全部图标、挂件与装饰件按你的排序自动装页，装不下就顺延到下一页；左右滑动翻页，底部液态玻璃页标指示当前页位。第 1 页固定包含时钟英雄区、前八枚图标、月历与音乐播放器——任何屏幕高度都完整可见：空间不够时整页等比缩小（组件宽高同缩、比例不变，各页缩放一致），空间富余时按原始尺寸顶对齐、底部自然留白，与 iOS 主屏一致；其余条目严格按页高装页，装不下顺延后页。

默认第 1 页：时钟英雄区，然后是每天会点的八枚——对话 / 记忆库 / 社交圈 / 信箱 / 日志 / 日程表 / 音乐 / 说明书 钉在第 1 页，月历长条与音乐播放器紧随其后、同样固定在第 1 页；第 2 页从相遇卡挂件开始，依次是名片 / 好友 / 设置 / 应用 / 共读间 / 观影室（安装后出现） / 收藏夹 / 工作区 / 创意工坊 / 数据 / 视觉，再是便笺、日程等挂件，装不下的顺延后页，屏幕较高的手机第 1 页可能自动多容纳一排。已经保存过布局的话默认序不会覆盖，新增的图标与挂件接在布局末尾。

排列：长按任意条目进入编辑态，按住拖动即可换位，点条目左上角「−」快速隐藏，点空白或「完成」退出；拖到屏幕左右边缘悬停约半秒自动翻页，松手落在目标页。排序与显示 / 隐藏仍在设置 → Desk 统一管理，「恢复默认」一键回到出厂排列。

电脑 / 大屏：不止手滑——点底部圆点直接跳页，鼠标滚轮左右翻页，键盘 ← → 方向键翻页，按住鼠标左右拖拽同样翻页；鼠标悬停桌面时两侧还会浮现半透明的左右箭头按钮。

经典滚动：Visual → Deco 的「桌面布局」可切回上下滚动的老 Desk（含旧的 1–3 页装饰页逻辑），两种模式随时互切、互不丢数据。

Deco — 装饰小组件

纯装饰、没有任何功能的小摆件，在 Visual → Deco 添加与管理，最多 12 枚，随备份同步两端。八款可选：拍立得（单图＋手写标注）、叠拍立得（1–3 张照片错落叠放）、胶片条（2–4 张照片入格的负片条）、贴图（透明 PNG 效果最佳）、字牌（流光大字）、头像牌（自己 / 好友 / 双人三种，双人款中间的心会跳，头像跟随 Space 与好友配置实时变化）、心语签（玻璃药丸里的一句话）与极光。

尺寸分 1/3 宽（一行三枚）、半宽与整行三档；编辑器顶部有实时预览台，改款式、换图、换字都即时可见。装饰件与图标挂件同场参与拖排与自动装页；经典滚动模式下则沿用「第 2/3 页专放装饰件」的老规矩。

专属聊天背景（仅本机）

给某位 AI 单独设一张聊天背景，只在与 TA 的会话里生效；淡化背景滑杆（0–70%）在背景上叠一层随主题明暗的半透底色，字看不清就往右拉。入口有两处：Chat 会话抽屉 → 设置区「专属聊天背景（仅本机）」，或独立配置页右上 ⋮ 菜单第一项。面板顶部带 TA 的头像，预览区以两枚示意气泡实时演示效果。

这些设定只存在本机：不进备份、不参与文件夹同步、不去电脑端。气泡款式在 Bubble Lab 里定制（见下一节）；给某位 TA 单独指定气泡方案手机端暂未开放。

Bubble Lab — 水水的气泡实验室

聊天气泡的定制工作室，水水住在里面。入口两处：Desk 桌面的「Bubble Lab」图标（烧杯，默认在第 2 分屏），或 Visual → 气泡 →「Bubble Lab — 水水的气泡实验室」。底栏两页。

Sui's Lab：聊着改。说一句想要的样子（「粉色系液态玻璃」「蓝紫渐变」「再淡一点」），水水用执笔 API 一次性回一套气泡，随消息出实时预览与「穿上（全局）/ 存为方案」两键。微调走同一条对话，只改相关字段。它只能填气泡的字段表——底色与第二背景色、渐变角度、描边、圆角、字号、字色、模糊、发光、四角装饰与尾巴 SVG、九宫格外框——版面与布局不在表里，所以做不出鬼气泡。顶栏「执笔 · 名字」小签换执笔 API（与水水共用）；「清空」清对话、不动方案槽；等太久或报错提到 length / token / context 时清空再试。

气泡方案：当前全局预览的穿衣室、九条基础拉条（我方与 TA 同调）、撤销 / 恢复默认，十个方案槽各带迷你预览（穿上 / 删 / 存当前）。数据只存本机，不进备份。

Blog — 日志

创作空间。写日记、剧本、查阅书籍、邀请TA留言，或生成记忆。列表支持搜索标题、副标题、分类与正文；点击卡片进入阅读视图，文末可切上一篇 / 下一篇，顶部可调字号并显示阅读进度。右上角目录键展开目录抽屉：点分类名筛选，「新分类名称」一行在目录之上，× 删除分类；目录前方单列「TA 写的」分支，每位写过日志的 TA 一行，点名筛选。

分类区：进 Blog 先看到分类卡——全部分类、My Blog（你写的）、Friends Blog（TA 写的，点进去每位 TA 一张「昵称 Writings」，没有 TA 写过就不出现）三张大卡，拉线之下是你自建的分类，每张卡写着篇数、最新一篇的标题与日期，空分类也有一张。点进任一张就是该分类的日志卡片流，顶栏左侧出现返回键（顶替菜单键）回到分类区；右上角目录键、搜索与写日志照旧，从目录里点分类或输入搜索会自动离开分类区。密码日记本解锁后是同一套分类区。

共读间与观影室：见下方「Coread — 共读间」「Cinema — 观影室」两个分块。

TA 写的日志：API 页 → 全局设置 → 进阶指令「启用 Blog 写入」开启后，TA 可以在回复里写一篇日志（每条回复最多 1 篇，正文 5000 字内），落进以 TA 名字命名的分类、署 TA 的名，列表卡与阅读页标「✎ 某某 写的」，聊天里出现「已写入 Blog ·《标题》」卡片。这类日志只有你看得到：不进日志列表注入、不进任何提示缓存；开了日志检索、你按标题点名时 TA 才读得到，回执会注明作者。TA 归档后它的日志随它进密码日记本，取消归档即回来。

密码日记本：受密码保护的独立分类，与公开 Blog 完全隔离。日记内容对所有 API 默认不可见；6 位数字密码 + 密保问答与电脑端互认。解锁后顶栏与目录抽屉的「Blog」改为「Password Diary」，「修改密码与密保」在标题块下方；在日记本里写的日志自动落进日记本，编辑器顶部显示 WRITING MEMORIES...。

留言与批注：阅读页底部可邀请任一 API 留言；电脑端写下的批注在此同步展示。

Coread — 共读间

常驻在 Blog 里，不用安装：Blog 下栏「共读间」或 Desk 图标进入（都进 Blog 页内），关掉回到来的地方。一篇日志＝一本书，Markdown 照 Blog 的样子渲染分页；选一位 TA，读到哪聊到哪。聊天落在这位 TA 名下一条「共读 · 书名」话题频道里，不进主对话，频道里不注入工具与协议（记忆注入、Auto Memory 与「记忆库写入」保留）；你第一次开口时频道里落一道「共读」分隔线，退出再落一道「共读结束」，只翻书不聊什么都不留。

TA 读到什么：每句话只随附你此刻这一页的原文（长度可设）与前文梗概（每读若干字压一次，可关），TA 读不到后面的页，它申请整篇也会被拒。设置（阅读页右上「⋯」）：字号 / 行距 / 页边距 / 字体 / 纸色，翻页方式与震动，进度显示，TA 主动开口（默认关），附给 TA 的原文长度，前文梗概，回话时展开纸条区，纸条区，阅读时屏幕常亮。「目录」看章节（行首「第X章」或 Markdown 标题）与书签。TA 回复期间纸条区显示「正在想…」，开了思考链的模型回完后可点开 Thought process。

存什么：书从 Blog 现读不另存；只存读到哪、书签、前文梗概与设置，随备份。删除这条频道会一并清掉这本书的进度与书签。书架顶部「最近在读」按「书 × TA」各记一条，写明与谁读到哪，点哪条就接着和那位 TA 读（一本书可以先后和不同的 TA 读，各有各的进度；换一位没读过的 TA 会从最近一次的位置接着）；书架里的日志卡显示最近一次的进度与正文节选；「最近在读」每条右上角的 × 可删掉这条记录（这位 TA 在这本书的进度、共读频道及其纸条一并清掉，书与日志不动）。书页上的代码块按页宽折行，表格保持横向滑动并带一条细滚动条，在表格里横滑不会翻页。

Cinema — 观影室

Desk「应用」里打开开关安装，Desk 图标进入（网站目录里要有 apps 文件夹，见「部署为 PWA」）。选一段手机里的视频、可配一份 .srt / .vtt 字幕（UTF-8 / GB18030 都认），选一位 TA 一起看。聊天落在这位 TA 名下一条「观影室 · 片名」话题频道里，不进主对话，频道里不注入工具与协议，只留记忆注入与记忆库写入；看完关掉，Chat 频道侧栏可回看、可删。

TA 看到什么：每句话只随附播放点之前最近几条字幕、进度与前情梗概；识图的 TA 默认每句话附上此刻一帧画面（设置里可改成关 / 只在留影时）；相机键＝留影：夹住当前画面随下一句发出，再按换帧，点缩略图 × 取消，默认不落库，「留影存进聊天」打开才留在聊天里。没字幕又看不到画面时，TA 只知道进度和你说的话，会被明确告知不要描述画面、不要编台词。「整片聊聊」把整份字幕压成梗概，作为「看完了」那条消息的正文留在频道里，之后可以聊全片。

播放与全屏：舞台通栏黑底，横版视频按宽占满，竖版视频受设置里的高度上限约束、两侧留黑；舞台上方没有单独的顶栏——← / 片名 / 整片聊聊 / 设置与进度条、播放、«10 10»、字幕、倍速、弹幕开关都是画面上的浮层，点画面显示、播放中几秒后自动隐藏、暂停常显；舞台与聊天区之间是一条衔接条（TA 头像 · 与 TA 一起看 · 时间 · 条数）。弹幕开着时你和 TA 的话会飞过画面（你的蓝、TA 的白）。画面右下角的全屏键进入全屏：由浏览器接管系统栏，方向按设置里的「全屏方向」（默认跟随画面：横版横屏、竖版竖屏），全屏里可按转屏键切换；顶栏「←」或再按一次全屏键退出，底栏是播放 / «10 10» / 弹幕 / 倍速 / 字幕 / 转屏与留影 / 输入 / 寄出，可以在全屏里接着聊。浏览器不放行全屏时（如 iOS Safari）退回铺满页面的方式，方向由系统决定。存什么：视频与字幕文件一律不入库、不随备份，只记片名、文件名、大小、时长与上次字幕文件名，不记进度；「选一部片」每次都新开一条记录与频道（同一部片可以有多条记录），只有从观影历史里点那条记录再看才接着原来的频道与聊天；点记录先出「待开始」卡，按卡上的按钮重选同一个文件即从头再看。开播后会探一次文件能否随机读：这台机器读不了文件中间的话，只能顺着放、拖不了进度。删观影记录会连它的频道一起删，反过来在 Chat 里删频道也会清掉这部片的记录。在线平台视频与 DRM 内容不支持。

Letters — 邮局

Beyond 邮件箱，用于接收异步时空的信件。选择一位 AI 点击"接收信件"，TA 会根据对你的了解写信并投递——聊天记录、日志、记忆库的读取范围均由 API 设置决定。信封按邮编搜索，火漆一点即拆。也可以点「写一封信」先给 TA 亲笔写一封：没写完自动存草稿，寄出后 TA 读完来信写回信，你的信会作为一张可滑动的便笺贴在回信上，信封抬头由 To 变为 Re 以作区分。勾着 Lettre du diable 时，回信同样走彩蛋口径。

暗色主题下，邮局另有一项需确认后开启的特殊选项；开启后收到的信件将不同于常规信件，其信封邮票亦有区别。开启前请阅读提示。收到的信可一键生成记忆存入记忆库。

Calendar — 日程表

备忘录，用来记录纪念日、生日、计划与日程。AI 可读取临近事项，在聊天中自然提起或留下便笺。

日程表（Desk 图标，原名「日历」）：Desk 上的月历挂件为双卡式——左侧小圆角卡堆叠年份、月名与星期，白瓷实环大头像跨骑在两卡接缝上，右侧为更大的圆角矩形月格卡：事项日标点，仅今日以透明圆形包裹（不换字色、无描边）；两侧裸箭头翻月，点选日期即弹出当天事项清单。

新建：填写类型、标题、日期、时间、重复方式与备注。纪念日默认按年重复，计划与备忘默认单次。备注填写后会随日程一并提供给有读取权限的 AI，留空则不发送。

留言：AI 写的便笺按时间倒序排列，标注署名与关联事项。

设置：Home 页 → 设置 → Calendar 分区，控制日历总开关、节日提醒、每位 AI 的读取与留言权限、相遇纪念日与「相遇纪念日提醒」（开启后相识满 100 天 / 520 天 / 每一周年的当天与前后一天，进日程页与 TA 的【临近日程】；需读取日程）。总开关关闭后，AI 不再读取日程，也不写新便笺。留言依赖读取权限：关闭读取会同时关闭留言。另外开启 API 页 → 全局设置 → 进阶指令「启用日历写入」后，AI 还能先查询它可见的全部日程（相遇纪念日固定在第一条）拿到事项 id，再按你的要求新建、修改或删除事项。

关于提醒：提醒有两条路——你主动发消息时，有读取权限的 AI 会在消息末尾看到临近事项并自然提起；开启 API 页 →「定时推送」的「主动提醒日程 / 留笺」后，TA 也会在到点时主动提起临近事项并留下便笺。

ICode — 文件工作区

你与 AI 共用的本地文件区：文件按项目分组，你可以导入文本类文件，AI 可以在对话中新建项目、读写文件；你在 ICode 页看到的与 AI 操作的是同一份数据。

AI 怎么用它：平时 AI 只知道自己有 ICode。需要具体操作格式时，它会先申请阅读一份操作教程，随后用指令读取文件、新建文件（重名自动另存为「名 (2)」，整份覆盖需显式声明）、局部改写（按「找到 → 替换」修改，失败原因会回传给它）与新建项目。开启 DIY 页「文件解析库」后，它还能生成真实的 Word / PDF / Excel 文件；跑代码（ws_run）依赖桌面环境，手机端不执行。

Script 开关（自动 / 确认）：ICode 页顶部配置卡第一行。开启为自动模式：教程自动读取、文件操作直接执行，AI 可以在同一个回复气泡里连续多步推进；关闭为确认模式：教程与每一步操作都先弹出「允许 / 拒绝」卡，你批准后才继续，拒绝即停止。

AI 连续操作：配置卡第二行，自动模式下允许 AI 连续执行的工作区步骤数（0–6，默认 3）；申请教程不计次数。达到上限后 AI 会停下，等你的下一条消息再继续。

精细文件工具：配置卡第三行，默认关闭。开启后 AI 才获得两条面向大项目的指令——检索工作区与本会话附件（返回至多 20 处「路径:行号」命中及前后片段）与读取上下文（看整文目录、按起止行读一段、读某行附近），用来先定位再精读，避免为找一个函数读完整个大文件；两条都计入连续操作次数。

文件过长与截断：随消息上传的附件正文按「精细文件工具 → 附件正文上限」三档并入（省 15000 / 均衡 30000（默认）/ 全读 120000 字符），超出的部分截断并随消息自动附一份「行号｜该段首行」目录；AI 用检索 / 按行读取拿回的内容每次最多 6000 字符；其余工具与文件操作结果单次最多 12000 字符。大文件的正路是开启「精细文件工具」，让它先看目录、再按行精读；「全读」档每轮都把整份正文重发一遍，长会话容易撞模型上下文。

发送量控制：聊天界面与本机数据库保留完整过程；发给 AI 的历史副本会把已成功执行的大文件内容折叠成很短的归档标记（失败或未确认的操作保留原文），避免几万字的文件长期占用后续对话的上下文。

GitHub 分区：ICode 底部分区栏第二格。填入 GitHub 访问令牌（PAT，需勾选 repo 权限）连接后，可列出你名下最近更新的 50 个仓库、逐级浏览目录并预览文件。

「导入到工作区」会新建一个「GH·仓库名」项目供 AI 在对话里读改；改完回本分区「从工作区推回」，系统自动获取远端最新版本，按你填写的说明一次性提交到所选分支。令牌只保存在本机浏览器，不进导出备份、不提供给任何 AI；超过 500 KB 的文件与二进制文件会拒绝导入。

API 配置与 PWA 部署

基本概念

API Key 是你在 AI 服务商处的身份凭证，按用量计费。IB 不提供 Key，需要你自行申请。

Endpoint：请求地址。选择服务商后自动填入官方地址，使用中转站时改为中转站给出的地址。

模型：具体调用的模型名称，需与服务商文档一致。

方式一 — 官方 API

在服务商控制台创建 API Key，复制后填入本页，Endpoint 与模型保持默认即可。官方接口通常需要海外网络环境。

方式二 — 中转站 API

中转站（API 代理 / 聚合站）把你的请求转发给上游服务商，多数按 OpenAI 兼容格式工作。配置方法：服务商选「自定义」，接口地址填中转站给出的完整地址，模型名以中转站的模型列表为准。

接口地址怎么填：填中转站控制台标注的「API 地址 / Base URL」。保存时应用会自动整理「自定义」地址：补全 https://、去掉空格与多余斜杠；只填域名（如 api.example.com）或只到版本号（…/v1、…/api/v3）时，自动补上 /chat/completions。完整地址（…/v1/chat/completions、…/v1/messages、…:generateContent）原样保留。

报文格式自动识别：「自定义」不再固定为 OpenAI 格式——地址以 /messages 结尾按 Anthropic 格式请求，含 generateContent 按 Gemini 格式，其余按 OpenAI 兼容格式。同一个中转站常同时提供几种入口，用哪种由你填的地址决定；Claude 系模型建议走 /v1/messages 入口，思考链与提示缓存才能完整生效。

拉取模型列表：「自定义」下按钮会依次探测多个候选地址——地址同级的 …/models、站点的 /v1/models、Anthropic 与 Gemini 风格的 models 接口，以及 new-api 类站点的公开模型表——首个返回列表的地址即用；列表超过 10 个时按模型家族分组，并提供关键词筛选。来自公开模型表的列表列出站点全部模型，能否调用以你的密钥权限为准。拉取失败不影响对话，直接手输模型名即可。

常见失败原因：① 401 / 403——密钥错误、所在分组无权限或余额不足；② 返回的是网页而不是接口——地址填成了控制台页面，应填 API 地址；③ 跨域（CORS）——中转站未允许浏览器直接访问，应用运行在浏览器环境里、无法绕过，只能换站点或自建转发；④ 400——请求参数不被接受，先关闭「提示缓存」，仍不行再关闭思考链；⑤ 模型名不符——中转站的模型名常带前缀或别名，以其列表为准。

接口预设：服务商为「自定义」时，配置页 API Key 下方多一行「接口预设」：把当前的模型、接口地址与密钥起个名存成一套，下拉里选一套即换上并直接保存这张配置，可删。用来在同一张配置里切换多个中转站或多套模型。预设只存本机（含密钥），不进备份、不去电脑端。

说明：中转站能看到你的全部请求内容，请只使用可信站点；本应用不内置、不推荐任何中转站。

常见问题

为什么报 401 / 403？ — Key 无效或余额不足。404？ — Endpoint 或模型名有误。400？ — 请求参数不被接受，可尝试关闭提示缓存或思考链。网络错误？ — 接口未允许浏览器跨域访问，或当前网络无法直连。

怎么快速验证某个配置能不能用？ — API 页·工具分区可对每个配置发一次最小请求，验证 Key、地址与模型是否可用。

Desk 第 1 页怎么摆不下我想要的组件？ — 分页桌面按排序自动装页：把想要的条目长按拖到前面即可挤进第 1 页，装不下的自动顺延；屏幕越高，每页能装越多。

新出现的「设置」图标是什么？为什么在我这儿排在最后？ — 第 12 枚桌面图标，点按直达设置。老用户保留自己拖过的排列，新图标先追加在末尾（通常在最后一页），拖回想要的位置即可。

「工坊 / 好友 / 名片」三枚新图标是什么？ — 分别直达 DIY 创意工坊、Friends 好友名片墙与你的 Space 名片。老用户已拖过的排列不变，新图标追加在排列末尾（通常在最后一页），可拖回想要的位置，也可在 设置 → Desk 里隐藏。

怎么回到以前上下滚动的桌面？ — Visual → Deco →「桌面布局」选「经典滚动」，随时可再切回来，两边数据互通。

聊天背景把字衬得看不清？ — 专属聊天背景面板里把「淡化背景」滑杆往右拉，会在背景上叠一层随主题明暗的半透底色。

装饰件最多放多少？ — 12 枚，每枚图片压缩后总量约 0.9MB 内；叠拍立得最多 3 张、胶片条最多 4 张。

部署为 PWA

PWA（渐进式网页应用）指部署到网站后的网页可以「添加到主屏幕」，从主屏幕图标打开，外观接近独立 App。它仍然是网页，不会变成原生 App；数据也仍然保存在浏览器本地。整个流程免费，全程不需要写代码。

准备清单

需要一个支持 HTTPS 的静态网站空间（下文以免费的 GitHub Pages 为例），并把 5 个运行文件放在同一目录：① index.html；② ib-sw.js；③ manifest.webmanifest；④ icon-192.png；⑤ icon-512.png。要用观影室，再把 apps 文件夹（里面是 catalog.json 与 ib-app-cinema.js）原样放在同一目录下——Desk「应用」读的就是 apps/catalog.json，第一次联网打开后会随本站一起缓存。直接双击本地文件打开（file:// 方式）仍可使用大部分功能，但不会注册 Service Worker，也不会作为标准 PWA 安装。

第二步 · 上传到 GitHub Pages

GitHub Pages 是 GitHub 提供的免费网页托管，注册一个账号就能用。照下面六步走，全程点鼠标即可，不需要写任何代码。

② 新建仓库：点右上角「+」→「New repository」。Repository name 填一个短名字（比如 ib），勾选 Public，点绿色的「Create repository」。

熟悉 Git 的话，直接把这 5 个文件 push 到仓库，效果完全相同。

第二步（更省事）· Fork 仓库部署，一键跟进更新

手机端源码公开在 github.com/Sui-IB/InternalBeyond-Mobile。与其手动上传 5 个文件，不如直接 Fork（复制）这个仓库到自己名下：运行文件已经齐全、目录结构也对，以后发新版只需点一次「Sync fork」。

① Fork：登录 GitHub 后打开上面的仓库地址，点右上角「Fork」，保持默认设置，点「Create fork」。几秒后会跳到你名下的副本（网址形如 github.com/你的用户名/InternalBeyond-Mobile）。

② 开启网页服务：在副本仓库点「Settings」→ 左栏「Pages」→ Build and deployment 里 Source 选「Deploy from a branch」，Branch 选 main、文件夹选 /(root)，点 Save。

③ 拿到网址：等一到两分钟后刷新这一页，顶部出现你的专属网址，形如 https://你的用户名.github.io/InternalBeyond-Mobile/。用手机浏览器打开，看到应用界面即部署完成，之后按下方「第三步」安装到桌面。

④ 更新到新版：发布新版后，打开你的副本仓库页面，文件列表上方会出现「This branch is N commits behind」提示，点旁边的「Sync fork」→「Update branch」。等一到两分钟 Pages 自动重新发布；然后在手机上彻底关闭应用再打开一次（必要时再刷新一次）。ib-sw.js 是联网优先策略，会自动换成新文件。

更新会不会丢数据：不会。对话、记忆、设置都存在手机浏览器本地，与仓库里的文件无关；网址不变，数据就在。稳妥起见，大版本更新前仍建议到 Data 页导出一份备份。

Sync fork 提示冲突：说明你改过副本里的文件（例如换过图标）。最省事的处理是点「Discard commits」放弃自己的改动再同步，之后把改动重做一遍；或者改用手动上传方式，只替换 index.html。

改名与图标：Android 安装名称与图标取自仓库里的 manifest.webmanifest 与两张 PNG，改完提交到副本即可；这类改动会在下次 Sync fork 时触发上面的冲突提示。

与手动上传的关系：两种方式二选一，效果相同。已经手动部署过的不必迁移；想省事就新建一个 Fork 副本，在新网址上从 Data 页导入旧备份。

第三步（安卓）· 安装到桌面

① 用 Chrome 打开第二步拿到的网址（Edge、三星浏览器等同内核浏览器也可以），等页面完全加载。

② 点右上角「⋮」菜单，选「安装应用」；有些浏览器里这一项叫「添加到主屏幕」。

③ 确认后，桌面上会出现应用图标。从图标打开就是无地址栏的全屏应用，状态栏颜色跟随当前主题。

菜单里没有「安装应用」怎么办：先确认当前网址是 HTTPS；再分别直接打开同目录的 ib-sw.js、manifest.webmanifest、icon-192.png 与 icon-512.png，四个地址都应能正常显示；最后刷新页面一次。标准安装使用仓库里的静态 manifest，不再使用 blob: 运行时 manifest。

后台与通知：安卓上装成 PWA 后可以常驻后台，切走再切回通常不会丢失正在进行的对话；系统内存吃紧时仍可能被回收，长任务建议留在前台。

换机：装成 PWA 不会把数据一起搬走。换手机、换浏览器之前先在 Data 页导出备份，新机装好后再导入。

第三步（iOS / iPadOS）· 添加到主屏幕

① 用 Safari 打开第二步拿到的网址。这一步必须是 Safari——iOS 上只有它能把网页装成主屏幕应用，其他浏览器里这一项是灰色的。

② 点屏幕底部中间的「分享」按钮（一个带向上箭头的方框）。

③ 在弹出的菜单里向下滑，点「添加到主屏幕」。

④ 确认名称，点右上角「添加」。主屏幕上随即出现应用图标，点开即是全屏应用，刘海 / 挖孔区已按安全区留边。

iOS 的「七天规则」：Safari 会把长期没有打开的网站数据当作缓存清理，口径大约是七天。本应用启动时会向系统申请「持久化存储」，多数情况下会获批——获批后数据就不再被自动回收；这一项是否批准由系统决定，所以稳妥起见，请在 iOS 上养成定期到 Data 页导出备份的习惯。

图标与名称：iOS / 书签仍可在 API 页 → 工具 →「PWA 预留」卡里设置本机名称与图标，改完后需删除旧主屏幕图标再添加。Android / Chromium 的正式 PWA 安装为保证兼容性，名称与安装图标取自仓库里的 manifest.webmanifest、icon-192.png 与 icon-512.png。

已知边界：iOS 的主屏幕应用不支持网页推送式的后台常驻，切走较久再切回会重新启动（数据不丢，只是回到首页）；此外 iOS 不提供电量属性，<ws_phone/> 拿到的手机状态里电量一项会缺失，这是系统限制不是配置问题。

使用边界与更新

离线边界：首次联网打开后，界面与本地数据在离线时仍可使用；AI 对话、联网搜索、图像生成、GitHub、MCP / 外部工具等需要网络的功能，离线时仍然不可用。

更新：替换服务器上的 HTML 或 ib-sw.js 后，重新打开页面即会加载新版本（模板为联网优先）；Fork 部署的仓库点「Sync fork」即可（见第二步）；个别浏览器可能短暂沿用旧文件。需要清除该站点数据来强制刷新前，请先在 Data 页导出备份。

数据与备份：数据绑定在「该网址 + 该浏览器」的本地存储上。换域名、换浏览器、清除网站数据或卸载重装之前，务必先在 Data 页导出备份，再到新环境导入。

自定义名称与图标：PWA 预留卡继续控制本机 iOS / 书签图标、名称、状态栏主题色与安全区。Android / Chromium 的正式安装名称与图标由仓库中的 manifest.webmanifest、icon-192.png、icon-512.png 决定；发布者需要改这三个文件后再提交到仓库。

部署之后，隐私边界有什么变化

把文件放上网之后，「本地单文件」就变成了「一个你自己托管的小网站」。变化在哪里、哪些已经替你处理好，逐条说明：

数据仍然只在你手机上。对话、记忆、日志、工作区文件全部存在浏览器本地数据库里，本项目没有服务器、不上传、不回传。托管方（如 GitHub Pages）只提供这个 HTML 文件本身，看不到你的任何内容。

已经替你处理好的两处：① 全站启用 no-referrer——向 AI 服务商 / 中转站以及任何远程图片发请求时，都不会带上你的站点地址；② 启动时唯一的第三方请求是向 Google Fonts 加载字体文件（为保持全站原有字体观感而保留），内容只有样式表和字体本身、没有任何脚本，同样不携带站点地址；断网时自动退回系统字体，界面照常使用。

剩下必然存在的一条：AI 对话要发给服务商，所以服务商一定知道你的 IP 与对话内容——这是调用 API 的固有代价，与是否部署无关。介意的话只能自建中转或改用本地模型。

共享域名的风险（重要）：GitHub Pages 的 用户名.github.io 是整个账号共用一个网站域，你放在同一账号下的任何其它页面，理论上都能读到本应用的本地数据库。因此：这个账号下不要挂来路不明的页面；更稳妥的做法是给本应用单独用一个账号，或者绑定一个自己的域名。

公开仓库里放什么：运行文件包括 index.html、ib-sw.js、manifest.webmanifest 与两张 PWA 图标，不含任何密钥——API Key、GitHub 令牌都存在浏览器本地，从来不写进文件。上传前请确认你上传的是干净的原始文件，而不是自己改过并把 Key 写死进去的版本。

建议开启锁屏：部署之后从主屏幕一点就进，设置页 → 锁屏开启图案解锁，能挡住手机被别人拿去随手打开的情形（锁屏配置只存本机，不进备份）。

缓存与费用

提示缓存是什么：把每轮重复发送的前缀（人设、指令、历史）在服务商侧缓存，命中部分按折扣计费。本应用的请求结构已按稳定前缀设计，开关在各 API 配置里。

命中一直是 0 怎么排查：手机连电脑用 Safari / Chrome 远程检查，或在电脑端同配置复现，控制台搜「IB手机缓存诊断」。常见原因：对话太短未达门槛、端点不回传命中字段、该服务商没给这个模型隐式缓存。

各家口径速查：豆包仅 doubao-seed-2.0 及之后系列与 seed-code 有隐式缓存（前缀 ≥1024 tok，官方注明不保证命中；seed-1.6 / 1.5 只能走服务端 Context API）。Kimi 官方直连没有隐式缓存，想自动命中可改走阿里百炼部署的 kimi。智谱、百炼千问、xAI 为服务端自动。Gemini 从 2.5 系列起才有，2.0 没有。Claude 与 OpenAI 官方接口按各自规则自动命中。

数据管理

导出：Data 页 → 导出备份文件，覆盖手机端全部本地模块——名片与设置、API 配置、聊天与话题、记忆库与 Auto Memory、日历与便笺、日志 / 批注 / 分类、信件、社交圈动态、ICode 工作区等；与电脑版互认同一套备份格式。

导入：选择电脑版或手机版的 JSON 备份。同 id 记录以文件为准，其余数据不受影响；备份里手机端不认识的模块自动跳过。

两端设置的分工：语音转写、记忆系统设置、外部工具、日历设置与每个 AI 的接口参数两端共用同一份记录，改动互通；手机专属的显示偏好、锁屏与 MCP 配置单独存放，电脑版不读也不写，随备份原样往返。

PWA 预留：API 页 → 工具分区「PWA 预留（App Packaging）」卡（位于图像生成与连接测试之间）继续负责本机 iOS / 书签名称与图标、亮 / 暗状态栏主题色和安全区；Android / Chromium 正式安装改用仓库中的静态 manifest.webmanifest 与 192 / 512 PNG 图标，以提高可安装性。离线缓存由 Service Worker 提供：HTTPS 部署且同目录放置 ib-sw.js 时会自动注册，完整部署步骤见本页「部署为 PWA」。

密钥安全：所有 API 密钥仅保存在你的浏览器本地（IndexedDB），本项目没有服务器、不收集任何信息。需要说明的是：启用云端模型后，你的消息与勾选注入的资料会由浏览器直接发给你配置的服务商或中转站，它们能看到请求内容——请只填写你信任的地址。

存储位置：浏览器 IndexedDB（InternalBeyondDB v15）。界面与本地数据不依赖网络；AI 对话、联网搜索等在线功能除外。

⚠ 备份建议：数据仅存于浏览器本地，清除浏览器数据或换浏览器将永久丢失。请定期使用导出创建备份。

通话的「耳朵」就是上面的语音转写接口：配好了才能用嘴说，说完一句停顿约 0.7 秒自动发出（识别与生成期间麦克风暂不收音）。没配、或麦克风被拒 / 环境不支持时，通话照常打开并转「打字模式」：不申请麦克风、不收音，用「打字」键交流，TA 的声音与工具调用都不受影响。

任何 OpenAI 兼容的 /v1/audio/speech 接口都能接：SiliconFlow 的 CosyVoice2、OpenAI 的 tts，自建 GPT-SoVITS 一类网关也行——这就是给「AI 声音」留的口子。请求由应用内浏览器直接发出，接口需允许跨域（CORS）；合成失败会自动回落系统语音。注意：阿里百炼（dashscope）的 CosyVoice 只有 WebSocket 且要求握手头鉴权，浏览器直连不通，别把它的地址填在这里。
